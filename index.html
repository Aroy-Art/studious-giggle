About the runtimes

SQLRuns on AlaSQL

Only single SELECT statements are accepted, and a column alias can't be reused inside HAVING (repeat the expression). Column names in your result don't matter, only their order and values.

TSCompiled with Babel

Types are removed but not checked, so a type error won't stop your function from running. Tests have a 3-second time limit.
