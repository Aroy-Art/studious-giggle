Select & Return

Write the query or the function that returns the right data.

SQLRuns on AlaSQL

A few things differ from PostgreSQL or SQLite: only single SELECT statements are accepted, and a column alias cannot be reused inside HAVING (repeat the expression). Column names in your result do not matter, only their order and values.

TSCompiled with Babel

Types are removed but not checked, so a type error will not stop your function from running. Each function runs against hidden tests, with a time limit for infinite loops.
