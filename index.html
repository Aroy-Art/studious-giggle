About the runtimes

SQLAlaSQL, in your browser

  • One SELECT statement per run
  • Repeat expressions in HAVING; aliases don't work there
  • Answers compare column order and values, not column names
  • Numbers are compared to 2 decimals

TSTypeScript 5.6, strict mode

  • Type-checked by the real compiler, then run
  • Type errors don't stop the tests, but you need clean types to solve
  • ES2020 built-ins only, no DOM or Node APIs
  • Tests stop after 3 seconds
  • The first run downloads the compiler (~1 MB)
